# Documents Page

## Introduction

The Documents Page allows applicants to upload and manage the documents required for the admission process. The system automatically displays the documents required based on the applicant's details, such as nationality, category, education, seat type, and USN status.

---

## Main Features

### 1. Display Required Documents

The system evaluates the applicant's information and displays only the documents applicable to that applicant.

Documents may vary based on:

- Nationality (Indian or Foreign)
    
- Category
    
- Karnataka Residency Status
    
- Educational Qualification (12th / II PUC or Diploma)
    
- Selected Seat Type
    
- USN Availability
    

---

### 2. Upload Documents

Applicants can upload documents for each required document type.

**Supported File Formats:**

- PDF
    
- JPG / JPEG
    
- PNG
    

**Maximum File Size:**

- 20 MB
    

The system validates the selected file before uploading.

---

### 3. View Uploaded Documents

After uploading, applicants can preview their documents to ensure the correct file has been uploaded.

**Supported Preview Formats:**

- Images (JPG, JPEG, PNG)
    
- PDF Files
    

---

### 4. Download Documents

Applicants can download any uploaded document whenever required.

---

### 5. Delete Documents

If an incorrect document has been uploaded, the applicant can delete it and upload the correct document.

---

### 6. Upload Progress Tracking

The page displays:

- Total Required Documents
    
- Number of Uploaded Documents
    
- Upload Completion Progress
    

This helps applicants track pending document submissions.

---

## Process Flow

1. The applicant opens the Documents Page.
    
2. The system loads the applicant's application details.
    
3. The system identifies the required documents based on eligibility criteria.
    
4. The applicant uploads the required documents.
    
5. The system validates and stores the uploaded files.
    
6. The upload progress is updated automatically.
    
7. The applicant can view, download, or delete uploaded documents.
    
8. All required documents must be uploaded before final application submission.
    

---

## Important Information

- Only documents applicable to the applicant are displayed.
    
- Uploaded documents must be clear and readable.
    
- Only PDF, JPG, JPEG, and PNG file formats are accepted.
    
- Rejected documents must be corrected and uploaded again.
    
- All required documents should be uploaded before submitting the application.
    
- If an official semester result sheet is unavailable, applicants may upload a screenshot or photograph of the published result.
    

---

## Conclusion

The Documents Page provides a centralized platform for applicants to upload, view, download, and manage admission-related documents. It ensures that only relevant documents are displayed and helps applicants easily track the status and progress of their document submissions.
