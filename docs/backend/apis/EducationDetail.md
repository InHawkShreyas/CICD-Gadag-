# Education Detail API

- Base route: `api/EducationDetail`

Endpoints:
- `POST /api/EducationDetail` — Create education detail. Accepts `CreateEducationDetailDto`.
- `GET /api/EducationDetail` — Get all education details.
- `GET /api/EducationDetail/application/{applicationId}` — Get by application ID.
- `GET /api/EducationDetail/{id}` — Get by ID.
- `PUT /api/EducationDetail` — Update education detail.
- `DELETE /api/EducationDetail/{id}` — Delete education detail.
