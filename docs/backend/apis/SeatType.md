# Seat Type API

- Base route: `api/SeatType`

Endpoints:
- `POST /api/SeatType` — Create seat type.
- `GET /api/SeatType` — Get all seat types.
- `GET /api/SeatType/application/{applicationId}` — Get seat types for an application.
- `PUT /api/SeatType` — Update seat type.
- `DELETE /api/SeatType/{id}` — Delete seat type.
