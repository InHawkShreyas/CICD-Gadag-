# Degree API

- Base route: `api/degree`

Endpoints:
- `POST /api/degree` — Create a degree. Accepts `CreateDegreeDto`.
- `GET /api/degree` — Get all degrees.
- `GET /api/degree/by-university/{universityId}` — Get degrees by university ID.
- `GET /api/degree/{id}` — Get degree by ID.
- `PUT /api/degree` — Update degree.
- `DELETE /api/degree/{id}` — Delete degree.
