# Application Course Detail API

- Base route: `api/ApplicationCourseDetail`

Endpoints:
- `POST /api/ApplicationCourseDetail` — Create course detail for an application.
- `GET /api/ApplicationCourseDetail` — Get all course details.
- `GET /api/ApplicationCourseDetail/application/{applicationId}` — Get course details by application ID.
- `GET /api/ApplicationCourseDetail/{id}` — Get by ID.
- `PUT /api/ApplicationCourseDetail` — Update course detail.
- `DELETE /api/ApplicationCourseDetail/{id}` — Delete course detail.

Notes:
- Protected by authorization.
